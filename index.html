Sync across devices

Optional: back this app with a Google Sheet so every device shares the same log, and you can browse the raw data yourself in Sheets.
Not connected — set up a Google Sheet to sync across devices.
How do I set this up?
  1. Create a new Google Sheet (any name).
  2. Extensions → Apps Script, delete the placeholder code, and paste in the script from this app's repo: apps-script/Code.gs. Change the SECRET value at the top to a password only you know.
  3. Deploy → New deployment → type Web app → Execute as Me → Who has access Anyone → Deploy. Authorize it with your Google account when prompted.
  4. Copy the Web App URL it gives you (ends in /exec).
  5. Paste that URL and your SECRET above, then Save & test.
  6. Do the same paste on every other device/browser — they'll all read and write the same Sheet.

Local backup

This device's copy lives in its browser (localStorage). If you're not using sync above, export a backup now and then so a browser reset can't lose it.
